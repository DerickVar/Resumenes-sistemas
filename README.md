Resúmenes de Sistemas Digitales

Este repositorio contiene los resúmenes de las cuatro primeras semanas de la asignatura de Sistemas Digitales de la Universidad Nacional de Loja.

Contenido

Semana 1: Microcontroladores, arquitectura y operaciones binarias.

Semana 2: ESP32, pines GPIO, tipos de datos y pulsadores.

Semana 3: Temporizadores, cálculos y ejemplos prácticos.

Semana 4: Interrupciones externas, ISR y antirrebote.

Cada resumen incluye los conceptos principales y ejercicios desarrollados durante las clases.
